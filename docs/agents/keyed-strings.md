# Keyed-строки

Открывай этот файл, когда вопрос касается файлов `**/Keyed/*.xml`: их формата или того, где в коде используется ключ.

## Формат

Корневой элемент `LanguageData` содержит плоский список элементов:

- имя элемента — **ключ**;
- текст элемента — **строка перевода**.

```xml
<LanguageData>
  <FloatMenuContainmentRequires>{0_label} требует:</FloatMenuContainmentRequires>
</LanguageData>
```

Английские оригиналы лежат в `.Data/<DLC>/Keyed/*.xml`, переводы — в `<DLC>/Keyed/*.xml`.

## Как код использует ключ

Код вызывает `"ИмяКлюча".Translate(арг1, арг2, ...)`. Чтобы найти место использования, грепом ищи `"ИмяКлюча".Translate(` по `.Decompiled/**/*.cs`.

- Аргументу можно дать имя: `pawn.Named("PAWN")`. Тогда в строке он доступен и как `{PAWN}`, и по номеру позиции.
- Аргумент без `.Named(...)` доступен только по номеру позиции: `{0}`, `{1}`, ...

Что подставится в конкретный `{…}`, выясняй по [howto-resolve-placeholder.md](howto-resolve-placeholder.md).
