# Синтаксис `{...}`

Открывай этот файл, когда нужно разобрать конструкцию в фигурных скобках на части, проверить её синтаксис или понять, почему она не работает. Правила одинаковы для `**/Keyed/*.xml` и `**/DefInjected/**/*.xml`. Источник правил — `TryResolveInner` в `.Decompiled/Verse/GrammarResolverSimple.cs`.

## Сначала запусти скрипт

```
python tools/parse_placeholder.py "{точный текст конструкции}"
```

Скрипт разбирает конструкцию (с любой глубиной вложенности) и показывает её вид, Символ, Подсимвол и Аргументы. Доверяй его выводу больше, чем разбору «на глаз». Правила ниже нужны, чтобы понимать этот вывод. Всегда разбирай точный текст из файла или вопроса. Не подбирай ответ по похожему примеру из этого документа.

## Термины

| Термин | Что это | Пример |
|---|---|---|
| **Символ** | часть до первого `_`: число `N` или имя `ИМЯ`; указывает на аргумент вызова в коде | `PAWN` в `{PAWN_label}` |
| **Подсимвол** | часть после первого `_`: что именно взять у объекта | `label` в `{PAWN_label}` |
| **Функция** | `lookup` или `replace` в конструкции `{имя:...}` | `lookup` в `{lookup: {0}; Case; 3}` |
| **Аргумент** | значения после `?` (у Подсимвола) или после `имя:` (у Функции) | `год`, `года`, `лет` в `{0_numCase?год:года:лет}` |

## Три вида конструкции

Проверяй по порядку и остановись на первой сработавшей проверке:

1. Текст начинается с `{{` → **Экранирование** (вид 3).
2. Сразу после `{` идёт одно слово, а сразу за ним, **без пробела**, стоит `:` → **Функция** (вид 2).
   `{lookup: x; Case; 1}` — это Функция.
   `{lookup : x; Case; 1}` (с пробелом перед `:`) — уже не Функция, и такая запись почти наверняка ошибочна.
3. Иначе → **Символ/Подсимвол** (вид 1).

## Вид 1: `{Символ_Подсимвол?арг1:арг2:...}`

1. Всё до **первого** `_` — Символ. Если `_` нет, вся конструкция — это Символ, а Подсимвол отсутствует (подставляется значение по умолчанию для этого типа, в выводе `subsymbols.py` оно показано как `""`).
2. Всё после первого `_` — Подсимвол. Если в нём есть `?`, имя Подсимвола — это часть до **первого** `?`, а всё после него — Аргументы, разделённые `:`.
3. Повторные `_` и `?` внутри Аргументов — это обычный текст.
4. Пробелы по краям каждого Аргумента обрезаются: `{0_numCase?год:года:лет}` и `{0_numCase ? год : года : лет}` — одно и то же.

| Текст | Символ | Подсимвол | Аргументы |
|---|---|---|---|
| `{0}` | `0` | — | — |
| `{PAWN_possessive}` | `PAWN` | `possessive` | — |
| `{0_numCase?год:года:лет}` | `0` | `numCase` | `год`, `года`, `лет` |
| `{USER_gender ? использовал : использовала}` | `USER` | `gender` | `использовал`, `использовала` |

Список Подсимволов для типа объекта выводит `python tools/subsymbols.py <Тип>`.

### Подсимволы с Аргументами

Скрипт помечает их, но не говорит, сколько Аргументов нужно. Количество фиксировано:

| Подсимвол | Аргументы | Без Аргументов |
|---|---|---|
| `gender`, `genderResolved` | 2 (`муж:жен`) или 3 (`муж:жен:без рода`) | допустимо: вернёт название пола |
| `humanlike` | ровно 2 (`для людей:для животных`) | ошибка, пустая строка |
| `multiple` (число) | ровно 2 (`если больше 1:если 1`) | ошибка, пустая строка |
| `numCase`, `age_numCase` | ровно 3 для русского: формы для 1 / 2–4 / 5+ (`день:дня:дней`) | ошибка, пустая строка |
| `replace` (строка) | пары `"старое"-"новое"`, как у Функции `replace` | — |

`numCase` согласует слово с **числом**. С грамматическим падежом он не связан: падежи берутся
Функцией `lookup` из таблицы `Case`.

## Вид 2: Функция `{имя:арг1;арг2;...}`

После имени без пробела идёт `:`, а Аргументы разделяются `;` (**не** `:`). Функций в игре всего две (`LanguageWorker.ResolveFunction`):

- **`lookup`**: `{lookup: слово; Таблица; столбец}` ищет `слово` в таблице `WordInfo` (например, `Case` из `Case.txt`) и возвращает указанный столбец (по умолчанию `1`).
  Пример: `{lookup: {1_labelShort}; Case; 3}`.
- **`replace`**: `{replace: слово; "старое1"-"новое1"; "старое2"-"новое2"}` находит **первую** пару, у которой `"старое"` встречается в `слово`, и заменяет все такие вхождения. Если ни одна пара не подошла, `слово` возвращается без изменений. Пример:
  `{replace: {0}; "мужчина"-"нужен"; "женщина"-"нужна"}`.

⚠️ Если хотя бы одна пара `replace` записана не строго как `"старое"-"новое"` (не хватает кавычки, нет дефиса), вся конструкция **без записи в лог** превращается в пустую строку.

## Вид 3: Экранирование `{{...}}`

`{{X}}` выводится буквально как `{X}`. Внутри ничего не разбирается. (`{{X}` даёт `{X`: одна открывающая скобка служит маркером экранирования.)

Экранирование нужно только там, где тот же текст потом обрабатывает другой код, например счётчик количества в `ITabs.xml`, `WITabs.xml`, `FloatMenu.xml`:

```xml
<RemoveSliderText>Выгрузить {lookup: {0}; Case; 3} ({{0}} шт)</RemoveSliderText>
```

Первый `{0}` подставляет грамматика, а `{{0}}` доходит до слайдера как текст `{0}`, и слайдер сам вставляет туда число.

## Вложенность

- **Можно:** `{...}` внутри Аргументов, то есть после `?` (вид 1) или после `имя:` (вид 2). Вложенная конструкция вычисляется первой (глубина не ограничена), и в Аргумент попадает её результат.
- **Нельзя:** `{...}` на месте Символа, Подсимвола или имени Функции. В лог пишется `Tried to use nested symbol for something but a symbol argument`, и ничего не подставляется.

Пример (`CannotGenericWork`, `Core/Keyed/FloatMenu.xml`):
`{replace: {lookup: {1}; Case; 3}; "область"-""}` вычисляется так: `{1}` → `lookup` → `replace`.

## Ошибки и их симптомы

| Ошибка | Что происходит в игре |
|---|---|
| нет аргумента с номером `N` или именем `ИМЯ`; неизвестный Подсимвол | ошибка в логе, текст пропадает |
| Аргументы переданы Подсимволу, который их не принимает | ошибка в логе, значение подставляется, Аргументы игнорируются |
| неверное число Аргументов (см. таблицу выше) | ошибка в логе, пустая строка |
| пара `replace` не в формате `"старое"-"новое"` | пустая строка, **в логе ничего нет** |
| `{...}` не внутри Аргументов | ошибка в логе, ничего не подставляется |
| нет закрывающей `}` | ошибка в логе о непарных скобках |

Если конструкция не подходит ни под один вид, не угадывай: скажи об этом прямо и процитируй её.

## Шпаргалка

| Знак | Значение |
|---|---|
| `_` (первый) | отделяет Подсимвол от Символа |
| `?` (первый после Подсимвола) | начинает Аргументы Подсимвола |
| `:` внутри `?...` | разделяет Аргументы Подсимвола |
| `:` сразу после первого слова | превращает конструкцию в Функцию |
| `;` | разделяет Аргументы Функции |
| `{{...}}` | буквальный текст |
