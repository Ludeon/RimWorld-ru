# Вклад в проект

Спасибо, что хотите помочь с переводом RimWorld на русский язык!

## Процесс перевода

Полное описание процесса и организации командной работы — в [wiki](https://github.com/Ludeon/RimWorld-ru/wiki). Вкратце, при переводе и проверке PR стоит придерживаться следующих принципов:

* соблюдать правила русского языка и уже принятые в проекте конвенции;
* переводить смысл, а не буквальный текст оригинала;
* не использовать вывод машинного перевода без последующей вычитки;
* проверять результат вычиткой и, если возможно, прямо в игре — текст должен корректно отображаться в интерфейсе, соответствовать контексту и не противоречить уже переведённым терминам.

В wiki также есть глоссарий терминов и инструкция по работе с Git/GitHub — пригодится, если вы не знакомы с этими инструментами.

Обсуждение вопросов происходит в [чате Телеграма](https://t.me/joinchat/CEY0QEO8s3S-29d_uv1SaQ) и в [группе ВКонтакте](https://vk.com/rimworld_russian), а также на [теме официального форума разработчика](http://ludeon.com/forums/index.php?topic=2933.0).

## Настройка рабочего окружения

Чтобы не копировать файлы перевода в игру руками при каждом изменении, в репозитории есть PowerShell-скрипты, которые связывают эту папку с локально установленной RimWorld через junction (Windows) или symlink (Linux/macOS). Требуется [PowerShell 7+](https://learn.microsoft.com/powershell/scripting/install/installing-powershell) (`pwsh`).

```powershell
./script/setup.ps1          # найти/подтвердить путь к игре и настроить всё сразу; безопасно запускать повторно
./script/setup.ps1 -Remove  # убрать созданные ссылки
```

Скрипт настраивает две вещи для каждого установленного DLC:
* игра начинает читать перевод прямо из репозитория (вместо `Data/<DLC>/Languages/Russian`);
* в `.Data/**` появляются ссылки на английские исходники игры — удобно для сверки при переводе.

Кроме того, в `.Decompiled/` появляется декомпилированный C#-код игры (через [ILSpy](https://github.com/icsharpcode/ILSpy) — `ilspycmd`, версия закреплена в `.config/dotnet-tools.json`). По нему видно, что подставляется в плейсхолдеры и когда показывается строка. Для этого нужен [.NET SDK](https://dotnet.microsoft.com/download) (`dotnet` в PATH); без него шаг пропускается с предупреждением. Первая декомпиляция занимает несколько минут; при повторных запусках она пропускается, если игра не обновлялась, а после обновления выполняется заново.

Скрипт поддерживает стандартные флаги PowerShell для управления выполнением:

```powershell
./script/setup.ps1 -WhatIf            # показать, что будет сделано, без реальных изменений
./script/setup.ps1 -Remove -WhatIf    # то же самое перед удалением ссылок
./script/setup.ps1 -Confirm           # спрашивать подтверждение перед каждым созданием/удалением ссылки
./script/setup.ps1 -Verbose           # подробный вывод: какой DLC обрабатывается, какая ссылка создана/удалена
```

`-WhatIf` полезен перед первым запуском на новой машине или перед `-Remove`, чтобы увидеть план действий и не удалить лишнее. `-Verbose` пригодится, если непонятно, почему для какого-то DLC ссылки не появились (например, не установлен). Флаги можно комбинировать (`-Remove -WhatIf -Verbose`).

## Проверка перед пушем

CI (`.github/workflows/main.yml`) прогоняет набор Python-проверок переводов при каждом PR. Чтобы не ждать падения CI, тот же набор можно запустить локально — потребуется [Python 3](https://www.python.org/downloads/) (`python3` или `python` в PATH):

```powershell
./script/test.ps1
```

Скрипт проверяет:
* дефисы и неразрывные пробелы вокруг тире (`check_dash_format.py`);
* согласованность значений в макросе `PAWN_gender` (`check_pawn_gender.py`);
* отсутствие точки в конце `reportString` (`check_report_string_dot.py`);
* кодировку файлов (UTF-8 с BOM) (`check_utf-8.py`);
* валидность XML (`check_xml_format.py`);
* соответствие `Case.txt` содержимому `DefInjected` в `WordInfo` (`worldinfo_case.py`).

Скрипт завершается с ненулевым кодом, если хотя бы одна проверка не прошла — так же, как соответствующий job в CI.

## Помощь ИИ-инструментов

Если вы пользуетесь ИИ-ассистентом в IDE (Claude Code, Cursor, GitHub Copilot, Continue и т.п.) — инструкции для него лежат в [AGENTS.md](AGENTS.md) и `docs/agents/*.md`. Это открытый межплатформенный формат: большинство современных инструментов читают `AGENTS.md` автоматически, конкретный плагин не требуется. Там же описан вспомогательный CLI в `tools/` (например, `tools/subsymbols.py` — генерирует таблицу подсимволов `{СИМВОЛ_подсимвол}` прямо из декомпилированного кода игры).
