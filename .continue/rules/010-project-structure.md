# Структура проекта

Проект локализации компьютерной игры RimWorld на русский язык разбит на папки:

- Core/ - локализация основной игры
- Royalty/ - локализация DLC Royalty
- Ideology/ - локализация DLC Ideology
- Biotech/ - локализация DLC Biotech
- Anomaly/ - локализация DLC Anomaly
- Odyssey/ - локализация DLC Odyssey

В этих папках находятся файлы локализации игры на русский язык. Эти файлы (и вложенных) можно менять.

В каждой из перечисленных папок содержатся подпапки, соответствующие своим частям локализации:

- DefInjected/ - файлы в формате .xml, которые содержат xml-инъекции, переопределяющие строковые данные из дефов
- Keyed/ - файлы в формате .xml, содержащие только локализованные игровые строки в виде наборов "ключ-значение"
- Strings/ (не всегда есть) - простые текстовые файлы, содержащие таблицы и списки слов или их элементов, используемые при генерации игровых текстов для русского языка. Набор файлов уникален для русского языка и не обязан повторять Data/**/Strings/

В корне проекта также существуют вспомогательные папки, не включённые в репозиторий, но требуемые для работы с локализацией

- .Decompiled/ - исходный код игры
- .Data/ - оригинальные данные игры

## .Decompiled

Папка с декомпилированным исходным кодом игры. Декомпиляция осуществлялась при помощи инструмента ILSpy. Существует для получения информации о том, как именно строки перевода будут использоваться в игре:

- в каких игровых ситуациях будут отображаться те или иные строки локализации
- какие параметры будут подставляться в строки локализации
- как именно строки локализации будут читаться и обрабатываться игрой перед отображением

Файлы этой папки (и вложенных) нельзя менять.

## .Data

Здесь содержатся текстовые данные, отвечающие за наполнение игры, размещённые по папкам. Файлы этой папки (и вложенных) нельзя менять.

- .Data/Core/ - данные основной игры без модов и DLC
- .Data/Royalty/ - данные DLC Royalty
- .Data/Ideology/ - данные DLC Ideology
- .Data/Biotech/ - данные DLC Biotech
- .Data/Anomaly/ - данные DLC Anomaly
- .Data/Odyssey/ - данные DLC Odyssey

В каждой из перечисленных папок содержатся Junction-связи с соответствующими папками игры RimWorld, установленной локально:

- Defs/ - база данных игры с дефами в формате .xml
- Keyed/ - файлы в формате .xml, содержащие только игровые строки в виде наборов "ключ-значение"
- Strings/ (не всегда есть) - простые текстовые файлы, содержащие таблицы и списки слов или их элементов, используемые при генерации игровых текстов
