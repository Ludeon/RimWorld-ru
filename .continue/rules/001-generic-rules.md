# Правила для анализа и поиска

- Не угадывай и не выдумывай! Если что-то не нашёл — честно скажи об этом. Если не знаешь как искать — спроси напрямую!
- Не пиши для меня инструкции! Выполняй работу сам! У тебя должны быть все нужные инструменты для поиска и анализа. Если инструментов не хватает — сообщи об этом!
- Будь краток! На конкретный вопрос отвечай конкретным ответом!
