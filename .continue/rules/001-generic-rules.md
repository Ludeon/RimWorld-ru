# Правила для анализа и поиска

- Не угадывай и не выдумывай! Если что-то не нашёл — честно скажи об этом. Если не знаешь как искать — спроси напрямую!
- Если у тебя есть инструменты для поиска, анализа и модификации — используй их вместо того, чтобы писать мне пошаговую инструкцию; если инструментов нет — скажи прямо, не имитируй
- Отвечай по существу, без воды; объёмные разборы — только когда они действительно нужны

# Правила для конкретных путей

Эти правила не подключаются автоматически — открой соответствующий файл сам, когда работаешь с подходящим путём.

- **Keyed-строки** — применяется к `**/Keyed/*.xml`. Файл: `docs/ai-rules/rules/030-keyed-strings.md`
- **Символы и подсимволы `GrammarResolverSimple`** — применяется к `**/Keyed/*.xml`, `*/DefInjected/**/*.xml`. Файл: `docs/ai-rules/rules/035-grammar-symbols.md`
- **Defs** — применяется к `.Data/*/Defs/**/*.xml`. Файл: `docs/ai-rules/rules/040-defs.md`
- **DefInjected** — применяется к `*/DefInjected/**/*.xml`. Файл: `docs/ai-rules/rules/050-def-injected.md`

# Готовые сценарии

- **definjected-search** — Показывает, какие данные подставляются в DefInjected-строку, и какие подсимволы ещё доступны. Файл: `docs/ai-rules/prompts/definjected-search.md`
- **keyed-search** — Показывает, какие данные подставляются в Keyed-строку, и какие подсимволы ещё доступны. Файл: `docs/ai-rules/prompts/keyed-search.md`
