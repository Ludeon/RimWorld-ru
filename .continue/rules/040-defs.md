# Defs

Папки Defs - это база данных игры. Она содержит игровые определения или "дефы". Дефы представляют собой набор разбитых по папкам файлов в формате .xml, описывающих игровые сущности, состояния, ситуации, включая их текстовые данные.

## Типы дефов

По структуре файл дефов состоит из корневого XML-элемента `Defs`, в котором содержится плоская структура XML-элементов. Каждый элемент соответствует одному дефу. Тег каждого элемента указывает на тип дефа. Примеры типов: BodyDef, ComplexThreatDef, JobDef, ThingDef.

Каждый тип дефа соответствует одноимённому классу-наследнику класса Def в исходном коде игры (который лежит в `.Decompiled/`). Дочерние элементы дефа отражают структуру полей этого класса. Можно считать, что любой деф - это результат сериализации объекта класса-наследника Def.

## Структура дефов

- Каждый деф имеет уникальное название (не путать с именем типа дефа). Оно может быть указано в виде дочернего элемента `DefName`, а иногда в виде атрибута `Name`.
- Дефы имеют иерархическую структуру (как классы в ООП). Ссылка на родительский деф содержится в атрибуте `ParentName` XML-элемента дефа. Это значит, что где-то в проекте существует абстрактный деф с таким именем. Абстрактные дефы имеют атрибут `Abstract="True"`. Неабстрактные дефы такого атрибута не имеют.
- Имя папки, в которой непосредственно лежит файл дефа, не имеет значения и не указывает на какую-то конкретную информацию.
