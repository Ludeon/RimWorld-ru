# Defs

Папки Defs - это база данных игры. Она сождержит игровые опеределения или "дефы". Дефы представляют собой набор разбитых по папкам файлов в формате .xml, описывающих игровые сущности, состояния, ситуации, включая их текстовые данные.

По структуре файл дефов состоит из корневого XML-элемента `Defs`, в котором содержится плоская структура XML-элементов дефов:

- Имена всех XML-элементов дефов внутри одного файла одинаковые и заканчиваются на "Def". Например: BodyDef, ComplexThreatDef, JobDef, ThingDef. Это имя типа дефа.
- Каждый тип дефа соответствует одноимённому классу-наследнику класса Def в исходном коде игры (который лежит в `/Decompiled`). Дочерние элементы дефа отражают структуру полей этого класса. Можно считать, что любой деф - это результат сериализации объекта класса-наследника Def.
- Каждый деф имеет уникальное название (не путать с имененем типа дефа). Оно может быть в виде дочернего элемнта `DefName`, а иногда в виде атрибута `Name`.
- Дефы имеют иерархическую структуру (как классы в ООП). Ссылка на родительский деф содерждится в атрибуте `ParentName` XML-элемента дефа. Это значит, что где-то в проекте существует абстракный деф с таким именем. Абстрактные дефы имеют атрибут `Abstract="True"`. Неабстрактные дефы такого атрибута не имеют.

В самой папке `.Data/*/Defs/` никогда не ищи .xml-файлы дефов! Шаблон `.Data/*/Defs/*.xml` не найдёт ничего! Для поиска по дефам используй поиск только по **вложенным** папкам внутри папки Defs: `.Data/*/Defs/**/*.xml`! Имена подпапок между `.Data/*/Defs/` и самим .xml-файлом не указывают на тип дефов. Не ориентируйся на эти имена при поиске!
