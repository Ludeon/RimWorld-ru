Файлы в следующих папках:
  - ".Decompiled/**/*"
  - ".Data/**/*"

предназначены только для чтения. Не предлагай в них изменений
и не модифицируй их инструментами записи.

Используй их для анализа:
- какие данные подставляются в плейсхолдеры;
- в каких ситуациях вызывается строка;
- какая игровая сущность связана с переводимым текстом.
