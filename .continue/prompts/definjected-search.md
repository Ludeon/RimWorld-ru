description: Показывает, какие данные подставляются в DefInjected-строку
invokable: true
globs: "*/DefInjected/*.xml"
---

Выполни следующие действия:

1. Определи имя элемента указанной DefInjected-строки и список плейсхолдеров в ней.
2. Запомни имя папки, где находится файл с DefInjected-строкой. Это будет тип искомого дефа.
3. С помощью текстового поиска найди по всем файлам *.xml в папке Data/**/Defs/ и во всех вложенных папках деф найденного ранее типа, и конкретный элемент этого дефа, который должна модифицировать DefInjected-строка.
4. С помощью текстового поиска найди по всем файлам *.cs в папке .Decompiled/ и во всех вложенных папках класс, который соответствует типу найденного дефа, и конкретное поле, которое должна эта строка модифицировать
5. Проследи, какие значения подставляются в каждый плейсхолдер.
6. Кратко опиши игровую ситуацию, в которой строка показывается.
      
Если что-то не нашёл — честно скажи об этом, не выдумывай.
