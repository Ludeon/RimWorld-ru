---
name: Какие данные подставляются в DefInjected-строку
description: Показывает, какие данные подставляются в DefInjected-строку, и какие подсимволы ещё доступны
invokable: true
globs: "*/DefInjected/*.xml"
---

Выполни следующие действия:

1. Определи имя элемента указанной DefInjected-строки и список плейсхолдеров в ней (`{0}`, `{ИМЯ}`, `{ИМЯ_подсимвол}`, `[ИМЯ_подсимвол]`).
2. Запомни имя папки, где находится файл с DefInjected-строкой. Это будет тип искомого дефа.
3. С помощью текстового поиска найди по всем файлам *.xml в папке Data/**/Defs/ и во всех вложенных папках деф найденного ранее типа, и конкретный элемент этого дефа, который должна модифицировать DefInjected-строка.
4. С помощью текстового поиска найди по всем файлам *.cs в папке .Decompiled/ и во всех вложенных папках класс, который соответствует типу найденного дефа, и конкретное поле, которое должна эта строка модифицировать.
5. Проследи, какие значения подставляются в каждый плейсхолдер, и определи C#-тип каждого значения (это важно для шага 6 — см. [035-grammar-symbols.md](../rules/035-grammar-symbols.md), подсимволы зависят от типа объекта, а не от имени переменной).
6. Для каждой переменной вида `{ИМЯ_...}`/`[ИМЯ_...]` по определённому на шаге 5 типу объекта найди в [035-grammar-symbols.md](../rules/035-grammar-symbols.md) полный список подсимволов, доступных для этого типа, и покажи его переводчику — не только тот подсимвол, что уже использован в строке, но и остальные доступные варианты.
7. Кратко опиши игровую ситуацию, в которой строка показывается.

Если что-то не нашёл — честно скажи об этом, не выдумывай.
