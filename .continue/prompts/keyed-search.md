---
name: Какие данные подставляются в Keyed-строку
description: Показывает, какие данные подставляются в Keyed-строку, и какие подсимволы ещё доступны
invokable: true
globs: "**/Keyed/*.xml"
---

Выполни следующие действия:

1. Определи ключ указанной строки и список плейсхолдеров в ней (`{0}`, `{ИМЯ}`, `{ИМЯ_подсимвол}`, `[ИМЯ_подсимвол]`).
2. С помощью текстового поиска найди по всем файлам *.cs в папке .Decompiled/ и во всех вложенных папках места, где к этой строке осуществляется доступ по строковому ключу через extension-метод `GrammarResolverSimple.Formatted` или `Translator.Translate`.
3. Проследи, какие значения подставляются в каждый плейсхолдер, и определи C#-тип каждого значения (это важно для шага 4 — см. [035-grammar-symbols.md](../rules/035-grammar-symbols.md), подсимволы зависят от типа объекта, а не от имени переменной).
4. Для каждой переменной вида `{ИМЯ_...}`/`[ИМЯ_...]` по определённому на шаге 3 типу объекта найди в [035-grammar-symbols.md](../rules/035-grammar-symbols.md) полный список подсимволов, доступных для этого типа, и покажи его переводчику — не только тот подсимвол, что уже использован в строке, но и остальные доступные варианты.
5. Кратко опиши игровую ситуацию, в которой строка показывается.

Если что-то не нашёл — честно скажи об этом, не выдумывай.
